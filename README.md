## Dev scripts

A repository to keep a collection of useful scripts for our development team.

[pr-progress](./pr-progress/README.md) generates single HTML file with PR progress based on open PRs for a label

[mock-central](./mock-central/README.md) tiny mock mSupply central server for testing Open mSupply sync integration locally

[loadtest-data-collection](./loadtest-data-collection/README.md) Windows/PowerShell harness for collecting Postgres stats, perfmon counters, logs and a replayable traffic capture *while* an Open mSupply server is under load (the load itself is generated separately, e.g. the k6 harness in [open-msupply#12235](https://github.com/msupply-foundation/open-msupply/pull/12235))
