## Dev scripts

A repository to keep a collection of useful scripts for our development team.

[pr-progress](./pr-progress/README.md) generates single HTML file with PR progress based on open PRs for a label

[fault-proxy](./fault-proxy/README.md) is a zero-dependency reverse proxy that sits between the omSupply client and server to inject typed GraphQL errors and connection failures for manual testing
